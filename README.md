Repositório referente ao segundo Desafio de Projeto do Bootcamp DIO e Reclame Aqui - Dados e IA na prática. 
📑 Organizador de Declaração para Imposto de Renda

🎯 Objetivo

O objetivo deste projeto é criar uma ferramenta simples e funcional para:

centralizar as informações necessárias para a declaração;
registrar dados de forma padronizada e validada;
reduzir erros de preenchimento;
facilitar a navegação entre as diferentes partes da planilha;
organizar documentos e dados fiscais de forma clara e prática.

A planilha pode ser utilizada como uma base para quem deseja se organizar ao longo do ano e chegar à época da declaração com tudo em mãos.

📌 Funcionalidades

A ferramenta foi pensada para unir praticidade e controle, tudo dentro do Excel. Entre os destaques:

menus de navegação para acesso rápido às diferentes seções;
validações automáticas para garantir a consistência dos dados inseridos;
interface amigável e visualmente organizada;
estrutura pensada para facilitar a leitura, o uso e a manutenção.

⚙️ Como funciona

A planilha foi estruturada como um agregador de dados, permitindo que o usuário insira e acompanhe informações relevantes para a declaração em um único lugar. Os menus de navegação conectam as áreas da ferramenta, enquanto as validações automáticas orientam o preenchimento e evitam entradas incorretas.

Com isso, o usuário mantém uma visão geral das suas informações e economiza tempo na hora de declarar.

🧮 Conceitos aplicados

Este projeto trabalha com os seguintes conceitos e capacitações:

organização de planilhas: estruturação lógica de abas, tabelas e fluxo de dados;
estética de planilhas: formatação consistente, paleta de cores harmônica e hierarquia visual para uma interface profissional;
personalização: menus, hiperlinks e atalhos que adaptam a ferramenta ao uso do dia a dia;
validação de dados e uso de fórmulas em Excel;
estruturação de informações para facilitar leitura e manutenção.

🖼️ Estrutura do projeto

O repositório contém:

uma planilha em Excel com a ferramenta de organização para Imposto de Renda;
um arquivo README.md com a documentação do projeto;
capturas de tela da ferramenta com exemplos.

🚀 Como usar
Faça o download da planilha disponível neste repositório;
Abra o arquivo no Microsoft Excel;
Utilize os menus de navegação para acessar as seções da ferramenta;
Preencha os campos com suas informações, respeitando as validações;
Use os links rápidos e os dados reunidos como apoio na hora de fazer sua declaração.

🛠️ Tecnologias utilizadas
Microsoft Excel
Validação de dados
Menus de navegação e hiperlinks
Formatação e personalização de planilhas
